# Evaluation Metric Mapping

| OpenScholar-style concept | eNH3-Bench analogue |
| --- | --- |
| Citation accuracy | Field grounding accuracy |
| Correctness / rubric score | eNH3 field accuracy |
| Hallucinated citations | Validation hallucination |
| Expert evaluation | Minimal human verification |
| Coverage | Evidence coverage by reaction family and validation type |
| Self-feedback | Rule-based draft feedback |

The mapping is conceptual. eNH3-Bench remains a local field-level benchmark, not
a long-form scientific RAG system.
