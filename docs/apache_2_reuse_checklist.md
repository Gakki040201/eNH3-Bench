# Apache-2.0 Reuse Checklist

- Is the material substantial source code, or only an idea?
- Does the original file contain copyright headers?
- Does the upstream project include a NOTICE file?
- Did we retain required attribution notices?
- Did we mark modified files?
- Did we avoid implying endorsement?
- Did we record the reuse in `docs/code_reuse_log.md`?
- Did we keep Apache-2.0 license text available in `LICENSES/Apache-2.0.txt`?
