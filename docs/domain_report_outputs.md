# Domain Report Outputs

The eNH3 domain report summarizes reviewed gold records for manuscript planning
and quality control. It is not a final scientific conclusion by itself.

The report is useful for:

- Checking coverage across reaction families.
- Checking validation-control reporting.
- Identifying high-risk records for additional human review.
- Building manuscript tables from reviewed gold.

Large-scale trend claims require a representative corpus and reviewed gold
labels. The report should guide review and table preparation, not replace
domain expert interpretation.
